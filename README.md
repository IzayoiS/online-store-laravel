# E-Commerce Web App 🛒

A modern e-commerce web application built with **Laravel** (backend) and **Vue.js** (frontend).  
Easily manage products, carts, and orders with secure authentication and an intuitive admin dashboard.

## ✨ Features

-   User authentication (login/register)
-   Product management (CRUD)
-   Shopping cart & checkout
-   Order management
-   Admin dashboard for products & transactions

## 🛠️ Tech Stack

-   [Laravel](https://laravel.com/) – Backend API & Authentication
-   [Vue.js](https://vuejs.org/) – Frontend UI
-   [MySQL](https://www.mysql.com/) – Database
-   [Bootstrap/Tailwind] – Styling (sesuaikan dengan yang kamu pakai)

## 📂 Installation

### Backend (Laravel)

```bash
cd backend
composer install
cp .env.example .env
php artisan key:generate
php artisan migrate
php artisan serve
```
